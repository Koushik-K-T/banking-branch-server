⚠️ Audit logs are generated every minute by audit_logger.sh and stored in /data/audit/. Only the auditors group has write access. Managers have read-only access. Logs are compressed and moved to /data/reports/ at 6:00 PM daily.

📋 Audit Logging Details

PropertyDetail
Script/scripts/audit_logger.sh
Storage Path/data/audit/
LVM Volumelv_audit (15 GB) on vg_branchdata
File FormatAUDIT_YYYYMMDD_HHMMSS.log
FrequencyEvery minute via cron
Write Accessauditors group only
Read Accessauditors, managers, itadmin
Processed At6:00 PM — compressed and moved to /data/reports/
Ingest Log/var/logs/branch/audit_ingest.log
