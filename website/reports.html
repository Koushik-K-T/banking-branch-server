✅ Daily audit reports are generated automatically at 6:00 PM by audit_report.sh. Reports summarise all events, counts by action and user, and are stored in /data/reports/.

📊 Report Generation Pipeline

StepWhat Happens
1audit_report.sh triggers at 6:00 PM via cron
2All AUDIT_*.log files in /data/audit/ are read and processed
3Total, successful, and failed event counts are computed
4Events are grouped by action type and by user
5Each log file is compressed with gzip and moved to /data/reports/
6AUDIT_REPORT_YYYYMMDD.txt summary is written to /data/reports/
